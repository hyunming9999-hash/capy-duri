# 카피두리

둘이 쓰는 카피바라 테마 웹앱. GitHub Pages에 올려 두고 휴대폰 홈 화면에 추가해서 쓴다.

- 오늘 어디야? — 버튼을 누를 때만 위치를 핑으로 찍어 지도에서 서로 확인
- 옷입히기 놀이하실? — 카피바라에게 상의 50벌·하의 50벌 입히기 (`js/clothes.js`)
- 카피바라 산책시키실? — 도트 공원 산책, WebRTC 음성 대화(연결 정보만 `rt/voice`로 교환)
- 오늘 무슨 날이지? — 달력, 일정/예약/기념일, 둘의 일기
- 오늘 뭐 입지? — 전신 사진 위에 옷 사진을 올려 보고 서로 평가
- 오늘 뭐 먹지? — 지도 검색, 찜 목록, 룰렛
- 오늘 무슨 게임하지? — 오목, 배구, 짝 맞추기, 사목, 유자 받기
- 오늘 얘기나 하지? — 톡, 사진, 스티커
- 오늘 뭐 보실? — 유튜브 같이 보기

데이터는 Firebase Realtime Database의 `rooms/<방 코드>` 아래에 저장된다. 방 코드는 초대 링크에만 들어 있고 이 저장소에는 없다.
보안 규칙은 `database.rules.json` 내용을 Firebase 콘솔의 Realtime Database → 규칙에 붙여넣는다.

주소 뒤에 `?mock=이름`을 붙이면 Firebase 없이 한 브라우저 안에서만 도는 연습 모드로 열린다.

## AI 코디 요청 처리 (Claude용 절차)

앱의 "오늘 뭐 입지? → AI 코디 요청"은 `wear/requests`에 요청만 남긴다. 사용자가 Claude 채팅에서 "코디 요청 처리해줘"라고 하면:

1. 방 코드가 필요하다(초대 링크의 `#join=` 뒤). 사용자에게 초대 링크를 받는다. 저장소나 메모에 적지 않는다.
2. `python3 tools/coordi.py fetch <방코드> <폴더>` — 대기 중인 요청별로 전신 사진(`base.jpg`)과 옷 사진(`item1.jpg`…)을 내려받는다.
3. 이미지 생성 도구로 "전신 사진 속 사람에게 옷 사진의 옷을 입힌" 사진을 만든다. 얼굴·체형·자세·배경은 그대로 두고 옷만 바꾸도록 지시하고, 요청의 한마디(`note`)를 반영한다.
4. `python3 tools/coordi.py post <방코드> <요청ID> <결과사진>` — 룩북에 올리고 요청을 지운다. 만들지 못했으면 `fail`로 사유를 남긴다.
